프로젝트 소개	카메라·마이크와 Jetson Orin Nano를 조끼형 웨어러블로 결합해, 에스컬레이터·엘리베이터·개찰구 등의 위치·상태·방향을 접촉 없이 실시간 음성으로 안내하는 온디바이스 AI 보행 보조 시스템. YOLO 탐지, Optical Flow 방향 분석, SmolVLM 설명, Whisper STT·gTTS 음성을 하나의 파이프라인으로 통합한다.
개발 배경
및 필요성	점자블록 적정설치율 4.0% 등 열악한 인프라와 접촉 후에만 정보를 주는 기존 수단의 한계를 넘어, 동적 정보를 접촉 이전에 안내해 독립 보행과 안전을 높인다.
프로젝트 특·장점	문·개찰구 상태 탐지와 Optical Flow 방향 판단, 다수결·쿨다운 오탐 보정을 완전 온디바이스로 구현해, 서버 전송형 기존 앱과 차별화된다.
주요 기능	영상 수집·전처리, 편의시설 탐지(YOLO), 에스컬레이터 방향 분석(Optical Flow), 엘리베이터·개찰구 상태 판단, SmolVLM 주변 설명, Whisper STT·gTTS 음성 입출력, 통합 파이프라인, Flask 웹 모니터링.
기대효과 및
활용 분야	독립 보행·안전 향상, 낮은 운용비·국산화, 개인정보 보호를 기대. 지하철·버스, 상업시설, 공공·의료시설, 장애인 고용, 스마트시티 인프라에 활용 가능.

I. 프로젝트 개요
 1. 프로젝트 소개
  1) 프로젝트 정의
 
     - 카메라·마이크와 NVIDIA Jetson Orin Nano 엣지 컴퓨팅을 웨어러블(조끼) 형태로 결합하여, 시각장애인이 에스컬레이터·엘리베이터·개찰구 등 이동 편의시설의 위치·상태·이동 방향과 주변 상황을 물리적 접촉 없이 실시간 음성으로 안내받도록 지원하는 온디바이스 AI 보행 보조 시스템
 2) 기획 의도
 
    - 흰지팡이·점자블록 등 기존 보조 수단은 물리적 접촉 이후에만 정보를 제공 → 접촉 이전에 시설의 상태·방향을 미리 알리는 "사전 인지형" 시스템으로 전환
    - 단순 객체 탐지를 넘어 상태(문 열림/닫힘, 개찰구 통과 가능/불가)와 움직임(에스컬레이터 방향)까지 이해하는 AI로 확장
 2. 개발 배경 및 필요성 
  1) 제작 동기
    - 2023년 말 기준 국내 등록 시각장애인 약 24만 8천 명 (전체 장애유형의 9.4%)
   - 흰지팡이·점자블록은 물리적 접촉 이후에만 정보를 제공하는 수동적 수단
    - 에스컬레이터 방향, 엘리베이터·개찰구 상태 등 동적·미세 환경 정보의 사전 감지가 불가능
   - 최근 5년간 서울 지하철 에스컬레이터 넘어짐 사고 257건 (월평균 4~5건)
  2) 목적
    - 엣지 AI 카메라로 시설의 위치·상태·방향과 주변 상황을 접촉 없이 실시간 감지·음성 안내하여, 공공시설 독립 이용과 보행 안전 수준을 획기적으로 향상하는 것을 목표로 함

 3. 프로젝트 특·장점
  1) 유사 제품과의 비교
    - 기존 시각장애인 보조 앱은 대부분 스마트폰에서 서버로 영상을 전송해 객체를 인식하는 방식
→ 통신 의존·지연이 크고, 정적 위치 인식에 그치며, 화면 터치 조작이 필요
  2) 기능적·기술적 차별성
    - 상태 탐지: 위치뿐 아니라 문 열림·닫힘, 개찰구 통과 가능·불가를 상태 클래스로 학습·탐지
     - 동적 인식: 에스컬레이터 ROI에 Optical Flow를 적용해 상·하행·정지 판단
　   - 온디바이스 엣지 AI: 서버 없이 Jetson에서 전 과정 처리 → 무지연 실시간성·통신 불안정 환경 동작·개인정보 보호
　   - 접근성: SmolVLM은 버튼 요청 시에만 실행, 화면 조작 없이 버튼·음성만으로 사용
  3) 독창성
    - "상태 탐지 + 동적 방향 판단 + 요청 기반 VLM + 완전 온디바이스"를 하나의 웨어러블 파이프라인으로 통합

3. 주요 적용 기술 
본 프로젝트는 시각장애인의 이동 과정에서 필요한 정보를 실시간으로 제공하기 위해 객체 탐지, 움직임 분석, 시각언어모델, 음성 인식 및 음성 합성 기술을 결합한다. 카메라와 마이크를 통해 입력된 영상과 음성은 Jetson Orin Nano에서 처리되며, 분석 결과는 스피커를 통해 사용자에게 전달된다.
전체 처리 과정은 다음과 같다.
영상 및 음성 입력 → 객체 탐지 및 상태 판단 → 움직임 분석 → 주변 상황 설명 → 안내 문장 생성 → 음성 출력

1) YOLO 기반 이동 편의시설 객체 탐지
YOLO 기반 객체 탐지 모델을 이용하여 에스컬레이터, 엘리베이터 버튼, 엘리베이터 문, 개찰구 등 시각장애인의 이동에 필요한 시설을 탐지한다.
YOLO는 한 번의 신경망 연산으로 객체의 종류와 위치를 동시에 예측하는 실시간 객체 탐지 모델이다. 처리 속도가 빠르므로 Jetson Orin Nano와 같은 엣지 디바이스에서 실시간 영상 분석에 적합하다.
모델은 입력 영상에서 다음 정보를 출력한다.
	탐지 객체의 종류 
	객체의 위치를 나타내는 바운딩 박스 
	탐지 결과의 신뢰도 
	객체별 상태 정보 
엘리베이터 문과 개찰구는 단순히 위치만 탐지하는 것이 아니라 상태별 클래스로 학습한다.
예시는 다음과 같다.
	엘리베이터 문 열림 
	엘리베이터 문 닫힘 
	개찰구 통과 가능 
	개찰구 통과 불가 
탐지 신뢰도가 기준값보다 낮은 결과는 제거하고, 여러 프레임에서 동일한 결과가 반복적으로 탐지된 경우에만 최종 상태로 판단한다. 이를 통해 순간적인 오탐지로 인한 잘못된 음성 안내를 줄인다.

2) Optical Flow 기반 에스컬레이터 방향 판단
에스컬레이터는 객체의 위치뿐만 아니라 현재 이동 방향을 판단해야 한다. 이를 위해 YOLO로 탐지된 에스컬레이터 영역을 ROI로 설정하고 Optical Flow를 적용한다.
Optical Flow는 연속된 영상 프레임 사이에서 픽셀이 이동한 방향과 크기를 계산하는 기술이다. 영상 내 동일한 지점의 밝기가 짧은 시간 동안 유지된다는 가정을 이용하여 움직임 벡터를 추정한다.
Optical Flow의 기본 관계식은 다음과 같다.
I_x u+I_y v+I_t=0

여기서 u와 v는 각각 수평 방향과 수직 방향의 이동량을 의미한다.
본 프로젝트에서는 에스컬레이터 ROI 내부의 평균 이동 벡터를 분석하여 다음 상태를 구분한다.
	상행 
	하행 
	정지 
	판단 불가 
전체 영상이 아닌 탐지된 에스컬레이터 영역에만 Optical Flow를 적용하여 주변 사람과 차량의 움직임이 분석 결과에 미치는 영향을 줄이고 연산량을 절감한다.
카메라 흔들림이나 보행자의 움직임으로 결과가 불안정할 수 있으므로, 여러 프레임의 방향 결과를 종합하여 최종 상태를 결정한다.

3) VLM 기반 주변 상황 설명
YOLO는 사전에 학습된 객체만 탐지할 수 있으므로, 학습 데이터에 포함되지 않은 장애물이나 복잡한 주변 상황을 설명하는 데 한계가 있다. 이를 보완하기 위해 VLM을 적용한다.
VLM은 이미지와 텍스트 요청을 함께 입력받아 영상에 포함된 객체와 상황을 자연어 문장으로 생성하는 모델이다.
사용자가 입력 버튼을 누르고 주변 설명을 요청하면 현재 카메라 프레임을 VLM에 입력한다. VLM은 다음과 같은 정보를 설명한다.
	전방의 사람과 차량 
	횡단보도 및 도로 상황 
	주변 장애물 
	객체 간 위치 관계 
	이동 시 주의가 필요한 상황 
예를 들어 전방 횡단보도에 보행자와 차량이 함께 존재하는 경우 다음과 같은 안내 문장을 생성할 수 있다.
“전방 횡단보도에 여러 명의 보행자가 건너고 있으며, 도로에는 차량이 많으므로 이동 시 주의가 필요합니다.”
VLM은 연산량이 크기 때문에 실시간으로 계속 실행하지 않고, 사용자가 요청하거나 YOLO만으로 상황을 판단하기 어려운 경우에 실행한다.

4) 물리 버튼 기반 사용자 입력
시각장애인이 복잡한 화면이나 메뉴를 조작하지 않고 기능을 실행할 수 있도록 물리 입력 버튼을 사용한다.
버튼은 Jetson Orin Nano의 GPIO 단자와 연결하며, 사용자가 버튼을 누르면 음성 입력 또는 주변 상황 설명 기능이 시작된다.
주요 처리 흐름은 다음과 같다.
버튼 입력 → 마이크 녹음 시작 → 사용자 음성 인식 → 요청 분석 → VLM 또는 안내 기능 실행
버튼 입력에는 디바운싱 처리를 적용하여 한 번의 버튼 입력이 여러 번 인식되는 현상을 방지한다.

5) STT 기반 음성 명령 인식
웹캠에 내장된 마이크로 사용자의 음성을 입력받고, Whisper 계열 STT 모델을 이용하여 음성을 텍스트로 변환한다.
음성 인식 결과를 기반으로 사용자의 요청을 구분한다.
	주변 상황 설명 요청 
	이동 편의시설 안내 요청 
	이전 안내 반복 요청 
	현재 상태 확인 요청 
마이크 입력은 16kHz 단일 채널 음성 형식으로 변환하여 STT 모델에 입력한다. 필요한 경우 실제 음성이 포함된 구간만 분석하도록 음성 구간 검출 기능을 적용할 수 있다.

6) TTS 기반 음성 안내
YOLO, Optical Flow 및 VLM의 분석 결과를 사용자가 이해하기 쉬운 안내 문장으로 변환한 후 TTS를 이용하여 음성으로 출력한다.
안내 문장은 불필요하게 길지 않도록 구성하며, 사용자의 행동 결정에 필요한 핵심 정보만 포함한다.
예시는 다음과 같다.
	“전방에 에스컬레이터가 있습니다.” 
	“에스컬레이터는 위쪽으로 이동하고 있습니다.” 
	“엘리베이터 문이 열려 있습니다.” 
	“오른쪽 개찰구를 통과할 수 있습니다.” 
	“현재 상태를 정확히 판단하기 어렵습니다.” 
생성된 음성은 블루투스 스피커를 통해 출력된다.

7) 연속 프레임 기반 결과 보정
영상 한 프레임만으로 상태를 판단하면 카메라 흔들림, 조명 변화 및 객체 가림으로 인해 오탐지가 발생할 수 있다.
이를 줄이기 위해 최근 여러 프레임의 탐지 결과를 저장하고, 다수결 방식으로 최종 상태를 판단한다.
예를 들어 최근 10개 프레임 중 일정 횟수 이상 동일한 객체와 상태가 탐지된 경우에만 음성 안내를 수행한다.
또한 동일한 내용이 계속 반복되지 않도록 안내 후 일정 시간 동안 같은 안내를 제한하는 쿨다운 기능을 적용한다.
분석 결과의 신뢰도가 낮거나 프레임별 결과가 일치하지 않는 경우에는 임의로 상태를 확정하지 않고 다음과 같이 안내한다.
“현재 상태를 정확히 판단하기 어렵습니다.”

8) Jetson Orin Nano 기반 엣지 AI 처리
영상과 음성 데이터는 외부 서버가 아닌 Jetson Orin Nano에서 처리한다.
엣지 AI 방식을 적용함으로써 다음과 같은 효과를 얻을 수 있다.
	네트워크 지연 없이 실시간 분석 가능 
	인터넷 연결이 불안정한 환경에서도 동작 가능 
	영상과 음성 원본의 외부 전송 최소화 
	개인정보 보호 강화 
	이동형 장치로 활용 가능 
Jetson의 제한된 메모리와 연산 성능을 고려하여 다음과 같은 최적화 방법을 적용한다.
	경량 YOLO 모델 사용 
	입력 영상 해상도 조정 
	필요 영역에만 Optical Flow 적용 
	VLM 요청 기반 실행 
	FP16 또는 TensorRT 기반 추론 
	불필요한 프레임 처리 최소화 

9) 웹 기반 모니터링 및 결과 검증
개발 및 테스트 과정에서 Jetson에 모니터를 직접 연결하지 않고도 처리 결과를 확인할 수 있도록 Flask 기반 웹 모니터링 기능을 사용한다.
웹 화면에서는 다음 정보를 확인할 수 있다.
	USB 웹캠 실시간 영상 
	YOLO 객체 탐지 결과 
	객체별 신뢰도와 바운딩 박스 
	에스컬레이터 방향 판단 결과 
	엘리베이터 문 및 개찰구 상태 
	시스템 실행 상태 
웹 모니터링 기능은 시각장애인 사용자를 위한 최종 인터페이스가 아니라, 개발자가 모델의 동작과 정확도를 확인하기 위한 테스트 및 검증 도구로 활용한다.

　   - (해결) 기능 단위로 담당을 분리하고 Notion 작업 보드로 담당·마감을 관리, Flask 웹 모니터링으로 각자 결과를 확인·검증

　   - (해결) SSH·Tailscale 원격 접속으로 공용 장비를 나눠 쓰고, 각자는 Colab에서 학습·검증을 먼저 끝낸 뒤 Jetson에서 통합 확인

    - (문제) Jetson Orin Nano의 제한된 메모리·연산 성능에서 YOLO·SmolVLM·STT를 동시에 구동하기 어려움
　  - (해결) 경량 YOLO 모델 사용, 입력 해상도 조정, ROI에만 Optical Flow 적용, VLM은 요청 시에만 실행, FP16/TensorRT 추론으로 최적화

　  - (문제) 카메라 흔들림·조명 변화·객체 가림으로 프레임 단위 오탐지가 발생함
　  - (해결) 신뢰도 임계값과 최근 여러 프레임 다수결로 최종 상태를 결정하고, 쿨다운으로 반복 안내를 방지하며, 불확실 시 상태를 확정하지 않고 "판단이 어렵다"고 안내

　  - (문제) 전체 화면에 Optical Flow를 적용하니 주변 보행자·차량 움직임이 에스컬레이터 방향 판단에 간섭함
　  - (해결) YOLO로 탐지한 에스컬레이터 영역(ROI)에만 Optical Flow를 적용해 간섭을 줄이고 방향 판단 정확도를 확보

　  - (문제) 초기 USB 웹캠의 화질·마이크 성능이 낮아 탐지·음성 인식 품질이 떨어짐
　  - (해결) 카메라 교체를 진행하고, 마이크 입력을 16kHz 단일 채널로 정규화해 STT 인식 정확도를 확보


 3. 프로젝트를 통해 배우거나 느낀 점 
    - 모델 정확도만이 아니라 신뢰도 보정·쿨다운 등 "안전하게 틀리지 않는" 설계가 실사용에서 더 중요함을 체감
    - 제한된 엣지 자원에서 경량화·ROI 처리·요청 기반 실행 등 자원과 정확도의 트레이드오프를 다루는 최적화 역량 습득
    - 사회적 약자의 실제 이동 시나리오를 기능·하드웨어(웨어러블)로 구체화하는 문제 정의·시스템 설계 경험














Ⅳ. 기대효과 및 활용분야 
 1. 프로젝트의 기대효과 
 　- (사회적) 에스컬레이터 방향, 엘리베이터 문·개찰구 상태 등 기존 수단이 주지 못하던 동적 정보를 접촉 이전에 실시간으로 제공 → 타인의 도움 없이 이동 가능, 심리적 위축 감소와 사회 참여 확대로 이어짐
　- (안전) 상태 기반 탐지와 신뢰도 보정(다수결·쿨다운·불확실 안내)으로 "잘못된 안내"를 줄여, 단순 알림형 서비스와 달리 오탑승·충돌 등 실제 사고 위험을 최소화
　- (차별성) 시중 보조 앱 대부분이 서버 전송형 단순 객체 인식에 머무는 반면, 본 시스템은 상태 탐지 + 동적 방향 판단 + 요청 기반 VLM을 하나의 온디바이스 웨어러블 파이프라인으로 통합 → 통신 의존·지연 없이 손을 쓰지 않고 사용
　- (경제/국산화·가격 우위) 외부 서버·클라우드가 필요 없는 온디바이스 구조로 통신비·서버 운용비가 들지 않아 지속 비용이 낮음. 고가의 해외 웨어러블 보조기기 대비 Jetson 기반의 합리적 단가로 국산화가 가능해 경제적 포용성을 실현
　- (프라이버시) 영상·음성을 외부로 전송하지 않고 기기 내에서 처리(엣지)하여, 보행 경로 등 민감 정보 유출 없이 개인정보 보호를 강화
　- (기술 확장·시장성) 저전력·실시간 멀티모달 엣지 처리 기술은 시각장애인 보조기기에 그치지 않고, 웨어러블 스마트글래스·지능형 안내 로봇·교통약자 안내 시스템 등 Physical AI 시장 전반으로 확장 가능


 2. 프로젝트의 활용분야 
　- (대중교통: 지하철/버스) 에스컬레이터 상·하행을 판별해 역방향 탑승을 막고, 개찰구 통과 가능 여부를 안내 → 사고 위험이 높은 환승 구간에서 넘어짐·오탑승을 예방하고, 안내원 도움 없이 스스로 통과 가능
　- (대형 상업시설·스마트빌딩: 백화점/몰) 엘리베이터 문 열림·닫힘 상태와 버튼을 인지해 조작을 돕고 매장 입구 위치를 안내 → 복잡한 실내에서 방향을 잃지 않고 목적지까지 독립적으로 이동
　- (공공기관·의료시설) SmolVLM 주변 설명으로 창구·복도 등 복잡한 실내 상황을 파악하고 자동문 진입 타이밍을 안내 → 낯선 공공·의료 공간에서도 접촉 없이 안전하게 이동하며 방문 부담을 낮춤
　- (장애인 고용 지원) 사무실 내 이동과 복사기·정수기 등 설비 접근을 도움 → 시각장애인 근로자의 업무 독립성을 높여 고용 유지와 직무 수행 여건을 개선
　- (재난·비상 상황) 비상구 표지와 대피 경로를 우선 인식해 안내 → 화재 등 긴급 상황에서 시야 정보 없이도 신속한 대피를 지원
　- (스마트시티 인프라) 웹 모니터링으로 수집·기록되는 보행 환경 데이터를 비식별화하여 축적 → 사고 잦은 구역을 파악해 점자블록·안내시설 개선의 기초 자료로 활용, 교통약자 전반을 위한 인프라로 확장
